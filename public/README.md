# public/

Static assets served directly by the server. Files here take priority over `frontend/`.

## Contents

- `indieforgeai-logo.png` — Main application logo
- Add images, icons, and other static assets here

## URL Access

Files in this folder are accessible at their root path, e.g.:
- `public/indieforgeai-logo.png` → `http://localhost:3000/indieforgeai-logo.png`
